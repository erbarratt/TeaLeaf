# Interaction (`Assets/Scripts/Interaction/`, namespace `Interaction`)

Hand targets, props, doors, lockpicking, chests, climbables, snap poses. Keep current with every change.

## Hand targets

- **`IHandTarget`**: anything a hand ray targets. **No highlighting** (reticle is the feedback). `CanBeTargetedFrom(rayOrigin)` (default true; `Ladder` back, `DoorBolt` other side refuse) - refused ray still stops there but finds nothing. `HasLongReach` (default false; `Grabbable` true) = reach `PlayerHandInteraction.pickUpRayLength` not `rayLength`.
- **`HandTargetRegistry`**: static `Collider → IHandTarget`; register `OnEnable`/`OnDisable`.
- **`IHandPushable`/`HandPushRegistry`**: `bool Push(point, displacement)` (displacement = blocked movement into the surface); true = moved, hand retries its move same frame. Static `Collider → IHandPushable`; `Door` registers its leaf. Used by `Player.HandPhysicalFollow` (each collider stopping the sweep, hit frames only) and `Player.PlayerBodyPushing`.

## Grabbable props

- **`Grabbable`** (`IHandTarget` + `IHandSnapTarget`, `[RequireComponent(Rigidbody)]`, colliders on Interactable, all in `HandTargetRegistry`). Carrying = `Player.PlayerHandHolding`.
  - **Authored hold pose**: `gripPoint` (child; empty = origin) + shared `snapProfile` (empty = hand on grip frame). `GetSnapPose()` = hand-visual pose to hold it as it lies; hand snaps out there, then carries it at that relative pose.
  - **`gripShape`**: `Point` (default, handles). `Cylinder`: grip point = middle of grippable part, Y = axis; `GetCylinderGripFrame()` = frame on surface (`cylinderRadius` 0.04) level with grab point (clamped to `cylinderGripLength` 0.1 about grip point), facing the axis, up along it (always same way up). **Side from head**: towards `headPosition`, turned `shoulderAngle` (20°) per hand like a hanging rope; ray-hit side, then grip point's back, are fallbacks. Draws grippable part when selected/in headset (`IDebugDrawable`).
  - `holdRadius` (guessed by `Reset()`), `LocalCentre` (solid colliders' middle, rotation-only local, `Awake()`): ball the hand collision grows to when carrying. `IsHeld`, `WorldCentre`.
  - `BeginHold(heldLayer)`: kinematic, collider objects to PlayerHands (originals kept: all read before any is set, as colliders can share an object), interpolation `None`. `EndHold(velocity, angularVelocity)`: non-kinematic with them (both zero = drop; else throw → `ContinuousDynamic`, own mode restored next `BeginHold()`), interpolation `Interpolate` (physics 50Hz; while held placed by parent, which interpolation fights). **Set `Interpolate` on every new prop.**
  - **Held prop pushes nothing**: `BeginCarry()` (at holder's `FinishReach()`, not reach start) sets `detectCollisions` false; `EndHold()` true. During reach: kinematic, solid, still. First `WakeNeighbours()` wakes Rigidbodies within 5cm of bounds (one `OverlapBoxNonAlloc`, shared 16 buffer) - disabling collisions doesn't wake sleepers, so stacked props would hang.
  - Stays on PlayerHands after `EndHold()` until holder calls `RestoreLayers()` once clear (else hand collision pushes the visual off the prop).
  - Finger pose = profile's (`BottleHold` for cylinders); no profile = input curl. No pose for cube/crate yet. `GetGripFrame(isLeftHand, grabPoint, headPosition)` (public, used by `GetSnapPose()` and Pose with Hand), `SnapProfile`.
  - `Stow()`/`Unstow()`/`IsStowed` (pack): stow = out of world (kinematic, no interpolation, colliders off) for the stower to move/scale; unstow = colliders on, still kinematic, caller then `BeginHold()`/`EndHold()`.
- **`ImpactNoise`** (`[RequireComponent(Rigidbody)]`, separate from `Grabbable`): all in `OnCollisionEnter()`.
  - Hardness = `collision.impulse.magnitude / mass` (not `relativeVelocity`: sliding onto the next floor piece collides without losing speed). <`minSpeed` (1) silent; up to `fullSpeed` (8) volume `minVolume` (0.25)→1, noise radius `minNoiseScale` (0.3)→1 of `cue`.
  - Surface: `SurfaceSounds.GetLoudness(SurfaceTag.Of(collider))` multiplies both; `muffle` = 1 - loudness. `surfaceSounds` optional (empty = stone).
  - One `SoundPlayer.Instance.Play()` at `GetContact(0)`, prop as source; no player = `cue.EmitNoise()`.
  - `minInterval` 0.15s per prop; prop-on-prop plays once (static last step+position: same step within 0.3m skipped). Kinematic/carried silent. Test props get one from `GrabbableTestProps`.

## Doors

Locks none/simple (pickable)/keyed. Unlocked door opens by its handle (ledge reach, hand snaps); 60° hand turn frees it; swings both ways or one; released within a few degrees of closed it shuts; open door moved by hand visuals and body; **handleless door pushed open from shut**; simple locks have a keyhole view; optional bolt worked from its own side only. Player half: `Player.PlayerHandDoors`.

- **`DoorLock`** (`None`, `Simple`, `Keyed`), **`DoorSwing`** (`BothWays`, `TowardsPlusZ`, `TowardsMinusZ`): serialized as numbers, append only.
- **`Door`**: turns about local Y, X along, Z through. `[RequireComponent(Rigidbody)]`, kinematic. **Angle set from code - no hinge joint/forces** (predictable, cheap, exact under a snapped hand); Rigidbody so collider moves cheaply and shoves props.
  - Hinge = origin + `hingeOffset` (X, Z; for pack models with mid-leaf origin: half width, sign = hinged edge), so `Door` goes on a variant root with pack LODs/collider as-is. `HingePosition` is the measuring point; `MoveTo()` sets position+rotation so origin orbits hinge. Leaf either side.
  - `swing` + `maxOpenAngle` (110) → `MinAngle`/`MaxAngle` via `GetLimits()` (`Awake()`); one is 0 for one-way; all clamps use them.
  - No `DoorHandle` child (`_hasHandle`) = no latch: a turning push frees it (`Push()`→`Unlatch()`) unless held shut; push against a one-way door does nothing. Still latches on closing (portal closes).
  - `IsLocked` (`startsLocked`); `IsLatched` (`IsOpen` = !latched); `Angle` from closed, + = clockwise from above; `IsBolted` (`SetBolted()`); `IsHeldShut` = locked||bolted (refused by `Unlatch()`; player code uses it for short stop + rattle). `keyId`.
  - `BeginHold()`/`EndHold()`/`IsHeld` (one hand), `Unlatch(soundPosition)`, `RattleLocked()`, `SetAngle()` (ignored while latched), `Lock()` (needs lock, shut)/`Unlock()`; context "Test Lock"/"Test Unlock" in Play. `TryGetBearing(worldPoint, out degrees)` (false within 0.1m of hinge line). `LeafCentre`.
  - **`Update()` = unheld motion; component disabled when at rest or held** (so `DebugDrawRegistry`/`HandPushRegistry` registration is `Awake()`/`OnDestroy()`). Order: pushed this/last frame → nothing; speed → `TickSwing()`; stopped within `closeAngle` (10°) → shuts at `closeSpeed` 60°/s and latches; else stays, disables.
  - `_angularVelocity` from `TrackVelocity()` (half old/new, in `SetAngle()`/`Push()`) so it swings on after release; decays `Exp(-swingDrag·t)` (`swingDrag` 3), stops <`minSwingSpeed` 5°/s, dead stop at limit or player. **Self-swing reaching closed latches** (only a hand takes it through).
  - `Push()` (hand sweep, body): open unheld (or shut handleless) door turns by bearing change of pressed point vs point+push (along door = nothing), ≤`maxPushSpeed` 360°/s, once a frame.
  - **`Physics.SyncTransforms()` in every `MoveTo()`**: Auto Sync Transforms is off.
  - **Never swings into player**: `Physics.CheckBox` of leaf (box from `Awake()`) at new angle vs `blockingLayers` (Player), blocked only if not already overlapping. Self-shutting/handle-pulled stops at body; body-pushed moves away, unaffected.
  - Optional `soundPortal` (closed while latched; set in `Start()` after portal `Awake()`), `latchCue`, `lockedCue`, `creakCue` (every `creakInterval` 25°), via `SoundPlayer`.
  - Gizmo: hinge line, swing arc with limits/close angle; red locked, yellow latched, green open (set `hingeOffset`/`swing` by eye).
  - **Pack-prefab door**: untick Static on every object, put on Interactable.
- **`DoorHandle`** (`IHandTarget` + `IHandSnapTarget`): trigger `BoxCollider`, Interactable, door child on the spindle, mid-thickness, door axes. **One handle, both sides**: volume pokes out both faces beyond anything solid; lever chosen by **head** side (`IsInFront()`). Grip frame: `standOff` 0.075, `gripAlong` -0.07 on X, `gripRadius`; facing door, up along lever towards that hand's thumb. `GetSnapPose(isLeftHand, isFront, leverAngle)` rotates about spindle, called every held frame. `SetLeverAngle()` turns optional `lever` (both levers) about local Z on change; `GetGripPoint(isFront)`. Visible levers have no colliders. Short reach.
- **`DoorBolt`** (`IHandTarget` + `IHandSnapTarget`): trigger `BoxCollider`, Interactable, door child at drawn knob position, door axes (X = shoot direction to free edge, Z out of front); `onFront`. Own side only (`CanBeTargetedFrom()`). `Slide` 0 drawn→1 shot over `travel` 0.05; `SlideAt(worldPoint)` unclamped; `SetSlide()` clamped, **0 while door open**, true on reaching an end, moves optional `bar`; `Release()` settles to nearer end. `IsShot`→`Door.SetBolted()`; `startsShot` (`Start()`). `GetGripPoint()`, `GetSnapPose(isLeftHand)` (knob, `standOff`, thumb up, `snapProfile`; test uses `DoorHandle.asset`). `slideCue` at ends. Gizmo: volume; selected, travel (green/red) and knob.
- **`KeyLock`**: keyed door/chest lock, axes as `PickableLock`. `door` or `chest` (neither = `Chest` on parent; `Chest.Centre` stands in for `Door.LeafCentre`), `faceOffset`, `unlockCue`. `KeyId`, `IsLocked`, `HasKeyIn` (`BeginKey()`/`EndKey()`). `FindInRange(point, range)` = nearest locked, keyless (static list). `GetFace(viewerPosition, out facePoint, out facing)` (facing: forward into door, up = lock up, right = viewer right). **`TurnsAnticlockwise(facing)`**: true if lock is right of `LeafCentre` from viewer. `Unlock()` → door/chest + cue. Either side. Keys: `Inventory.Key`/`Keyring`; player half `Player.PlayerKeys`.
- **`DoorKeyhole`**: **an opening grown in the leaf, not a second camera** (true stereo, nothing drawn twice, no magnification). Shape: circle + slot below (slot width = radius, depth = diameter): 2r × 4r. Empty door child at circle bottom, mid-thickness, X across, Y up.
  - Cut by leaf shader **`TeaLeaf/DoorLeaf`** (leaf material must use it); **picture only**, collider untouched. `Awake()` sets keyhole place in leaf space via `MaterialPropertyBlock` once (face axes × leaf scale = metres); `Apply()` sends size only on change.
  - Radius `restRadius` 5mm → `openRadius` 5cm as head goes `openStartDistance` 0.6 → `openFullDistance` 0.25, smoothstep, rate `openSpeed` 6/s. **Only while latched.**
  - Depth: `BuildWalls()` (`Awake()`) makes `Keyhole Walls` child: dynamic tube mesh, 46 tris, normals in, no shadows, leaf material + `wallColor` block (uncut). `BuildOutline()` (static, r=1, shared with gizmo; **must match shader `KeyholeDistance()`**): four runs, unshared join points (hard edges) - 300° arc in 20 pieces from slot right over top to left, slot left, bottom, right. `UpdateWalls()` on size change, no alloc, fixed bounds. Depth = `thickness`, 0 = leaf renderer bounds along forward. Keyhole and parents unscaled.
  - No `Update()`: static list; `Player.PlayerKeyholes` calls `FindInRange(headPosition)`, then `Tick(headPosition, deltaTime)` (false at rest+out of range)/`Close()` on that one.
  - `plateRenderers` (lock plates also cut): own `TeaLeaf/DoorLeaf` material and block (`BuildBlock(target)`), sized in `Apply()`; set `thickness` to plate's full depth. Door keyway keyhole-shaped; big lock's rectangular.
  - Gizmo: rest (yellow)/open (green) outlines 3cm either side.
- Handle profile `Assets/Data/Hand Poses/DoorHandle.asset` = copy of `BottleHold` (stand-in; tune in headset).
- **`DoorTestArea`** (`Interaction/Debug/Editor`, **TeaLeaf > Dev Room > Build Door Test Area**): 7m wall (Static, Environment) 2.5m ahead of camera, three 0.9×2.1m doorways: no lock, simple, keyed (both start locked). Door = unscaled hinge root, kinematic Rigidbody, leaf, handle 1m up, lever each side. Placeholder impact cue (latch/rattle) and creak (`PlaceholderSounds.Create()` first).
  - `SoundPortal` per doorway (area child, wired to `soundPortal`), 7×3×6m `SoundRoom` each side, `Sound Emitter Behind Doors` cube 2.5m beyond knocking every 3s (disable for silence).
  - No-lock: bolt 1.35m up on the door's back (side the area faces).
  - Simple: `Keyhole` (`DoorKeyhole` + `PickableLock`) 0.82m up with `Lock Plate` (cylinder, r 3.5cm, 6mm proud each face, no collider, `Assets/Art/Materials/LockPlate.mat`); leaf `Assets/Art/Materials/DoorLeaf.mat`.
  - Keyed: `Key Lock` (`KeyLock` + plate), key `red`; `Key Stand` (camera side, between simple and keyed) with red key and a blue one that opens nothing.
  - Adds if missing: `PlayerHandDoors`, `PlayerLockpicking`, `PlayerKeys` (Hands); `PlayerBodyPushing`, `PlayerKeyholes` (Player); pack/inventory (`Inventory.LootTestProps.EnsurePlayerComponents()`); **`Big Lock`** (`BigLock` + `BigLockDebug`) under `Gameplay` (keep unit scale - parts inherit; outside the area so rebuilds keep tuning) with `Assets/Data/Hand Poses/LockpickHold.asset` (copy of `RopeGrip`, stand-in) and placeholder cue. `PlayerKeys` key pose = `DoorHandle.asset` (stand-in).

## Lockpicking

Spec: `Assets/DEVROADMAP.txt` Phase 5; player half `Player.PlayerLockpicking`. **Angles = clock positions from the player's side, degrees clockwise from 12.**

- **`PickableLock`**: keyway middle, mid-thickness, X across, Y up, Z through (usually on the `DoorKeyhole`). `door`/`chest` (neither = `Chest` on parent; none = own locked state + `Unlocked` event), `faceOffset` (to face, where picks sit). `IsLocked`, `IsBeingPicked` (`BeginPicking()`/`EndPicking()`), `CanBePicked` (only `DoorLock.Simple`; warns otherwise). `GetFace(viewerPosition, out facePoint, out outward)`, either side. `Unlock()` → door/chest (door stays shut; until restart). Static list, `FindInRange(point, range)`. Gizmo: ring per face, red/green.
- **`BigLock`**: floating large copy **and the puzzle**. One per scene, built in `Awake()`, reused; `PlayerLockpicking` finds or makes one. Axes X player-right, Y up, Z into door; origin body middle; unscaled; no `Update()`.
  - Looks: body `faceRadius` 0.11, `bodyDepth` 0.05, dark rectangular keyway, rim marks at right pick's 4 stops and left sweep ends, picks `pickLength` 0.2 leaning `pickLift` 35°. `LockMeshBuilder` meshes, `TeaLeaf/LockFade`. **No colliders.**
  - Fade: `Show(target, position, rotation)`/`Hide()`; `Tick()` over `fadeDuration` 0.25s; 3 renderers share 2 own materials (see-through while fading, `_Alpha` written directly; solid when in; disabled when out), swapped only on change (`SetLook()`).
  - Puzzle: `PinCount` 3. Right: `rightStartAngle` 30, `CurrentStop` = start + `stopSpacing` 28 × (`PinsSet`+1); last stop unlocks. Left: `leftStartAngle` -30, `LeftSweep` 0-`leftArc` 120 anticlockwise. `TurnPick(isLeftPick, handPosition)`: angle = `Atan2(x, y)` of hand in lock space, `Mathf.DeltaAngle` from range middle, clamped (stateless, no wrap); within `deadRadius` 3cm of axis ignored. Right at stop (`stopTolerance` 1.5°, re-armed after 3× back) → `StopReached`, or all pins set → `Target.Unlock()`, `unlockCue`, `Unlocked`. `IsSearching` = right at stop with pin to find; `TickSearch()` (left held): `PinNearness` 0 at `pinFeelAngle` 10 → 1 at `pinSetAngle` 5; `HoldTimer` within set angle (reset on leaving); `pinHoldTime` 1s → `PinSet`, new pin. `ChoosePin()`: random, ≥`minPinGap` 20 from left pick (stretch cut out, no retry loop).
  - `ReleasePick(right)` before unlock: `PinsSet` 0, new pin (`WasReset` if lost); pick returns at `returnSpeed` 240°/s; left stays.
  - `HoldPick()`, `GetGripPoint()`, `GetSnapPose(isLeftPick)` (rope-style: up along pick, facing away; `snapProfile`, none = input curl), `CanBeWorked` (fade ≥ half), `IsActive`.
  - `pickCue` (`pickVolume` 0.4, `pickNoiseScale` 0.3) at stop, pin, reset, every `scrapeAngle` 25° of left sweep; **played from the real lock** via `SoundPlayer`.
- **`LockMeshBuilder`**: `Box(centre, size, rotation, color)`, `Cylinder(radius, depth, segments, faceColor, sideColor, centre = zero, turn = 0)` along Z (`turn` degrees about Z; 3 segments = prism, first corner +X) → one vertex-coloured mesh (`ToMesh()`); `CreateMaterial(seeThrough, minLight)`. Load time only. Also used by pack, keyring, blackjack, compass.
- **`BigLockDebug`** (`Interaction/Debug`, on Big Lock): `IDebugDrawable` in lock space: pick angles (white), stop (yellow), pin (red), pin squares (green set), hold bar; logs stage changes.
- Stand-ins: `LockpickHold` profile (copy of `RopeGrip`); sounds.

## Chests

Same lock kinds via `PickableLock`/`KeyLock` given the chest. Locked lid won't move; unlocked, hand lifts lid front. Player half in `Player.PlayerHandDoors`.

- **`Chest`** (on body; X along hinge, Y up, Z to front): `lockType` (`DoorLock`), `keyId`, `startsLocked`; `lid` child **on hinge line**, chest axes, turns about own X; `maxOpenAngle` 100, `closeAngle` 8; `openCue`/`closeCue`/`lockedCue` via `SoundPlayer`. Code-set angle, no joint: `AngleAt(worldPoint)` (`Atan2` up vs forward of hinge); `SetAngle()` (clamped; false/no move while locked; cues on leaving/reaching shut); `Release()` (<`closeAngle` drops shut); `RattleLocked()`. `IsLocked`, `Angle`, `IsOpen`, `Centre`, `Unlock()`, `Lock()` (lock + shut). No `Update()`, no Rigidbody (lid shoves nothing).
- **`ChestLid`** (`IHandTarget` + `IHandSnapTarget`): trigger `BoxCollider`, Interactable, lid child at front-edge middle, chest axes, short reach. `Chest` (parent), `snapProfile`, `GetGripPoint()`, `GetSnapPose(isLeftHand)` (facing in, turns with lid, every held frame).
- **`ChestTestArea`** (`Interaction/Debug/Editor`, **TeaLeaf > Dev Room > Build Chest Test Area**): three chests on stands 1.5m ahead, fronts to camera: none, simple, keyed (`green`; green key on stand to the right). ## Climbables

- **No mesh**: `ClimbableEdge`/`Ladder` = `BoxCollider`, `ClimbableRope` = `CapsuleCollider`, gizmos only. Visible items get a separate renderer the scripts ignore.
- **Grab volume (trigger) larger than its solid geometry** (Environment; physical hands stop on it). `PlayerHandInteraction` checks volumes containing the hand before the ray (rays from inside a collider miss it). **Solid geometry must not reach the volume surface** (rays tie, targeting flickers).
- All three `IDebugDrawable`: `DrawDebug(lines, detailed)` (false from `OnDrawGizmos`, true from `OnDrawGizmosSelected`), `DebugDrawRegistry` in `OnEnable`/`OnDisable`; cached collider after `Awake()`, else `GetComponent`.
- **`IClimbable`** (extends `IHandSnapTarget`, no members; grab starts climb; `PlayerClimbing` type-checks).
- **`IMantleable`**: `MantleEndsCrouched`, `CanMantleFrom(gripPoint, headPosition, headBelowTopAllowance)` (each frame gripped), `GetMantleLanding(feetPosition)`; `PlayerMantling` asks each gripped target. Edge: head within allowance of top; Ladder: hand on top rung.
- **`IZipLine`**: `IsZipLine`, `ZipSpeed`, `ZipAcceleration`, `Length`, `GetPoint(t)`, `GetClosestT(point)`, `GetZipDirection(headForward)`; sliding is `PlayerClimbing`'s.
- **`ClimbableEdge`** (`IHandTarget`, `IClimbable`, `IMantleable`): snap = ray hit onto box top-front line (clamped), facing wall, via `ClosestLipPoint()` (also mantle top height). **Axes: X along edge, +Y up, +Z out of wall to player.**
  - `isMantleable` (level edges only), `mantleEndsCrouched`, `mantlePoint` (real metres on its axes: `MantlePointWorld` = position + rotation × point, **not `TransformPoint()`** - stretched cubes); default top face 0.4m in from lip (`Reset()`/"Reset Mantle Point"). `moveHorizontallyToPoint` (default on): off = land at mantle point's height/depth but player's own position along the edge (feet square-on, clamped) - for long edges. `GetMantleLanding(feet)`.
  - `grabbableFromBothSides` (default off; walls, parapets, railings, sills): snaps to lip on the **head's** side (`IsBehind()`, vs box middle), frame facing in from there. Box spans full thickness overhanging both faces equally (off for ledges in a wall). **One two-sided edge, never two back-to-back** (overlap grabs far side). Top-centre mantle point.
  - Setup: solid on Environment + slightly larger trigger on Climbable. `OnValidate()` warns (clickable) if not trigger / not Climbable.
  - Gizmos: box faint, lip(s) bright; selected: mantle point or landing line.
- **`Ladder`** (`IHandTarget`, `IClimbable`, `IMantleable`): one `BoxCollider`, no rung colliders. `firstRungHeight`, `rungSpacing` (real metres, unscaled frame: position + rotation, size × `lossyScale`); count = what fits. Snap to rung nearest hit on centre line, ledge-style frame, `LadderRung` profile. Axes as edge. **Front only**: `CanBeTargetedFrom()` refuses origins behind rung line (-Z) unless `climbableFromBack` (frame flips to +Z). **Top exit = mantle**: own (`isMantleable` default on; hand on top rung; `mantlePoint` unscaled local, `mantleEndsCrouched`; default level with top, 0.4m behind back face) or a mantleable edge above. Top rung via `PlayerClimbing.LeftGrabPoint`/`RightGrabPoint` + `NearestRung()`. Gizmos: outline, rails, rungs; selected: rung spheres, side arrows, mantle point.
- **`ClimbableRope`** (`IHandTarget`, `IClimbable`, `IZipLine`): static line from position along local -Y for `length` (hanging, or on its side strung). Frame from rope direction.
  - `endPoint` (optional): straight to it, rotation/`length` ignored (`Length` = distance); read in `Awake()` only.
  - `sag` (0 = straight, e.g. zip lines): world-down parabola droop at middle (`GetPoint(t)` public - builders lay visible rope on it); `sagSegments` 8. Sag or end point (`UsesSegments`): `Awake()` `BuildSegments()` makes a trigger capsule per piece on a child (registered to the rope) and disables own capsule. Set before Play, scale 1, `sag` 0 when hanging.
  - Sizes own `CapsuleCollider` (Awake, OnValidate, `SetLength()`), metres / scale, `HideFlags.NotEditable`, always trigger; `length`/`grabRadius` (0.08) only controls; top fixed when `length` changes. Visible solid rope = child inside volume. `SetLength()`/`SetSnapProfile()` for rope-arrow ropes (`Player.PlayerArrows`).
  - `WarnAboutSetup()` (`OnValidate()`, clickable): not Climbable, or non-trigger child collider reaching ≥`grabRadius` from axis (by its own local box corners, not `Collider.bounds` - huge round angled ropes). Skipped when sagging.
  - `GetSnapPose()`: nearest point (clamped), facing rope, up towards top, `snapProfile` (`RopeGrip.asset`). **Side fixed, not hand's**: hanging = head side turned `shoulderAngle` 20° so wrist points at that shoulder (anticlockwise from above for right hand, clockwise left); strung = straight below. Grab side fallback only. Strung (within ~45° of level, `StrungMaxUpY`): up = along rope back towards player, against `headForward`. Per grab.
  - `isZipLine`: any grab slides at ≤`zipSpeed` 6 m/s (`zipAcceleration` 8) till release or end, then drop. Downhill if ends differ >5cm, else facing direction. No hand-over-hand.
  - Gizmos: line faint; selected bright + capsules. Exits as ladders.

## Hand snap poses

Used by ledges, ladders, ropes, props, handles, bolts, picks, keys. `HandSnapPose` (readonly struct: position, rotation, `Profile` whose fingers the hand plays, null = input curl), `IHandSnapTarget.GetSnapPose(isLeftHand, grabPoint, headPosition, headForward)` (two-sided edge uses head position, strung rope head forward). Target gives a model-agnostic grip frame; shared `HandSnapProfile` SO (Create > TeaLeaf > Hand Snap Profile) adds per-hand offsets and **the finger pose**, one asset per kind; no profile = bare grip frame, input curl. **Held things the hand places** (bow, arrow, pack): static `GripFrameInHand(profile, isLeftHand, handPosition, handRotation, out grip...)` = `Apply()` the other way round (null profile = hand pose); `PlaceInHand(profile, isLeftHand, held, handVisual, unscaledParent)` sets the held thing's world pose under an unscaled parent, then parents it to the visual keeping it (never drawn mirrored).
- **Finger pose = data, not clips**: `fingerRotations`, 16 local rotations in `HandSnapProfile.FingerBoneNames` order (thumb 1-4, index, middle, ring, pinky 1-3), shared by both hands (mirrored right visual has the same bone locals); `HasFingerPose`, `FingerRotation(i)`, `FindFingerBones(visual)` (by name, load time). Played by `Player.HandFingerPoser` (`Scripts/Player/CLAUDE.md`). No `HandPose` enum, no Animator pose states or clips.
- `Assets/Data/Hand Poses/`: `LedgeGrip`, `LadderRung`, `RopeGrip`, `BottleHold` (headset-tuned), stand-ins `DoorHandle` (`BottleHold` fingers), `LockpickHold` (`RopeGrip` fingers); held things `BowGrip` (`RopeGrip` fingers), `ArrowHold` (no fingers), `BowString` (`LedgeGrip` fingers), `PackHold` (`RopeGrip` fingers), offsets from the old hand-placement numbers / rough, all to pose with Pose with Hand. Props' own profiles are made here by Pose with Hand (`<prefab>.asset`).
- **`HandPoseWindow`** (`Interaction/Editor`, **TeaLeaf > Modify Prefab > Pose with Hand**; opened on a selected `Grabbable` prefab it starts on that): poses a hold without Play Mode. **Subjects** (popup, Previous/Next): held things first, `Held` enum, profile on a field in the Player prefab - **Bow** (`PlayerBow.bowProfile`, frame = bow origin), **Arrow** (`arrowProfile`, frame = nock, Z to tip; stun mesh placed by the longest arrow's length), **Bow String** (`stringProfile`, frame = nock of an arrow at `String_Rest` pointing through `Arrow_Rest`; in play the hand is held in this full pose on the string), **Pack** (`PlayerPack.packProfile`, frame = pack origin; chest from `Pack`'s fields, handle on the shown hand's side, a block where the spaces are) - then every `Assets/Prefabs` prefab with a root `Grabbable` (profile on its `Grabbable`). Plain `Instantiate` copies (`DontSave`; posed thing also `NotEditable`) at (20, 300, 0): the thing and a copy of the Player prefab's left or right hand visual (`PlayerHandVisuals.LeftHandVisual`/`RightHandVisual`, Animator removed, lossy scale kept), placed by the profile on the grip frame (props: `Grabbable.GetGripFrame()`; cylinder: head `_headOffset` (0, 0.3, -0.45) from the grip point). Hand moved with Unity's tools (Select Hand); fingers by a curl slider per finger (adds the same X to each joint) and per joint (inspector X curl, Y, Z; `TransformUtils` inspector rotation, Undo), or Select a bone + Rotate tool; Rest Fingers. Left/Right toolbar; **Mirror to other hand**: position x negated, rotation (x, -y, -z, w) in the grip frame. Edited pose held in a serialized `HoldPose` (survives reload/Play; copies destroyed on close, reload, play). Shows grip frame axes and head in the Scene view; warns when the profile is shared with other subjects (**New profile for this**). **Save**: offsets (0.1mm, 0.01°, Euler -180..180) and fingers into the profile; none = new `Assets/Data/Hand Poses/<prefab>.asset` (held things: `BowGrip`, `ArrowHold`, `BowString`, `PackHold`), filled before it becomes an asset and saved before the prefab (the prop's, or Player) takes it (saving the prefab reimports and would reload an unwritten new asset). Revert; leaving or closing with changes asks Save/Discard/Cancel (`hasUnsavedChanges`).
