# Tools/TextureGen

Rebuilds the project's own textures: smoke flipbook, cloud cubemap, the three street ground layers and the painted pipe maps. Outside `Assets`, so Unity never compiles it (it uses .NET's `System.Drawing`, which Unity lacks) and it never ships. Run from Windows PowerShell 5.1; each `.cs` is compiled on the fly by `Add-Type`.

- **`TextureGen.ps1 -Make Smoke|Clouds|Cobbles|Setts|Dirt|WetDirt|Pipes|All [-Out <folder>]`**: writes straight over the project textures (their `.meta` files stay, so materials keep their links; Unity reimports on focus). `-Out` writes to a folder instead, for trying changes. Run with the defaults, it reproduces the textures in use exactly.
- **Tuning** is in each generator's public static fields (defaults = the textures in use); change, rerun, look.

| File | Makes | How |
|---|---|---|
| `SmokeSheet.cs` | `Assets/Art/Textures/SmokeFlipbook.png` (2048, 6 x 6, 36 frames) | Soft column of smoke low in each cell (the chimney prefab's renderer pivot is set for that). Noise wraps in time over the 36 frames, so the loop is seamless. Alpha = smoke, colour near-white (the material tints). |
| `CloudSky.cs` | `Assets/Art/Textures/Sky/SkyClouds.png` (vertical-strip cubemap, 2048/face) | 3D noise by view direction (faces meet seamlessly): top-lit cumulus from just below the horizon to straight overhead, clear below that; warm lit tops, cool shade. Colour = the cloud's light (black = clear), alpha = thickness (texture imports alpha from input, DXT5). |
| `Cobbles.cs` | `Assets/Art/Textures/Ground/Setts_<Albedo,Normal,Height,Occlusion,Smoothness>.png` (in use) and `Cobbles_*` (spare) | Two layouts, same painted style and palette: **setts** (`UseSetts()`) - near-square stones in running-bond courses, uneven course heights, each joint leaning and each stone side set back its own amount, tight joints, flat tops over a narrow chamfer with a crisp light line on it, deep relief (height uses nearly the full range), chisel facets across the tops (each a tilted plane lit by its tilt), more tone and hue from stone to stone, every edge lightly chipped and a tenth of stones pitted (clustered small pits) with deeper chips; **cobbles** (field defaults) - irregular rounded stones from a wrapping power diagram, no rows. Every map from one height field; normal and occlusion derived from it. Tiles exactly. Setts courses run along texture x (turn with the material's `_CobbleRotation`). |
| `PolyHavenGround.cs` | `Dirt_*`, `WetDirt_*` in the same folder | Poly Haven CC0 scans (`rock_ground`, `mud_forest`; 2k PNG maps fetched once into `Downloads/`, git-ignored) with each map matched to the target mean and spread the ground blend is tuned for. Wet dirt height flat (0); normals flattened. Noise-made dirt looked synthetic, so these two are scans. |
| `PipesPainted.cs` | `Assets/Art/Materials/Environment/Pipes/Pipes_Painted_<Albedo,Normal,Mask>.png` (4096), on `MVillage_Pipes_Painted.mat` (all `Assets/Prefabs/Environment/Pipes`) | Repaints the pack's pipe atlas (`STYLZ_MVillage/_Assets/Pipes/Mats`: albedo, normal, MRAO; re-imported on a fresh clone) as painted cast iron: the pipes' own dark blue-grey under an all-over mottle of crisp darker, lighter and rust-brown dabs at two sizes, dark rust gathered in creases and broad patches with warm specks, grime in creases, faint scratches, only a thin dim warm light on raised edges (never bright outlines). Creases and edges from the pack normal's curvature at two scales. Normal = pack's plus small dents. Mask is URP Lit's packing (R metallic, G occlusion, A smoothness); the material uses it as both Metallic/Smoothness and Occlusion map, with metallic, smoothness and occlusion strength at 1. Outside the atlas islands everything is 0. |

Pipe import settings (in their `.meta`): albedo sRGB, normal a Normal map, mask linear with alpha from input, max size 4096. Ground maps: 2048, tiling, OpenGL normals (+Y up), greyscale saved as grey RGB (imported single-channel, linear). Import settings live in each texture's `.meta`; the scripts never touch them.
